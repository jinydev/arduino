Ghibli 2D anime style, a charming programming metaphor scene comparing C-style char arrays with C++ String objects for Arduino memory. On a wooden worktable, Dorothy arranges neat solid wooden letter compartments (char array) with exact fixed slots, showing safe and fast static memory. Beside her, assistant cat Jiny inspects an expandable magical pouch (String object) that stretches easily but fragments memory. In the background, an Arduino Uno outputs clean text strings to a glowing serial terminal screen.
