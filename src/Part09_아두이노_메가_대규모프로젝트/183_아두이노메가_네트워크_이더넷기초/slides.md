## 1. 아두이노를 네트워크에 연결하는 2가지 길

![아두이노 로고](../../img/arduino_logo.png)

* **1. 이더넷 쉴드 (Ethernet Shield - W5100 / W5500)**:
* 랜선(RJ45) 케이블을 직접 꽂는 유선 방식!
* 무선 간섭이 전혀 없어 24시간 365일 가장 안정적인 통신 보장.
* **2. 와이파이 모듈 (ESP8266 / ESP32 / WiFi 쉴드)**:
* 선 없이 무선 공유기에 접속하는 Wi-Fi 방식!
* 사물인터넷(IoT) 스마트홈 기기 제작에 가장 널리 쓰여요.

### 🌐 유선 LAN vs 무선 Wi-Fi

> 이번 슬라이드에서는 '1. 아두이노를 네트워크에 연결하는 2가지 길'에 대해 자세히 살펴보겠습니다. 화면의 다이어그램과 사진을 함께 참고해 주시기 바랍니다. 첫 번째 핵심은 이더넷 쉴드 (Ethernet Shield - W5100 / W5500)이며, 두 번째로는 랜선(RJ45) 케이블을 직접 꽂는 유선 방식!입니다. 여기에 덧붙여 무선 간섭이 전혀 없어 24시간 365일 가장 안정적인 통신 보장. 내용까지 함께 이해해 두시면 완벽합니다. 이 원리는 아두이노 시스템 전체를 관통하는 핵심 논리이므로 머릿속에 꼭 정리해 두시기 바랍니다.

## 2. 네트워크의 기본 주민등록증: IP와 MAC 주소

![](./img/dorothy_multi_arduino_talk.jpg)

* **MAC 주소 (물리적 주소)**:
* 전 세계 모든 랜카드에 유일하게 부여된 고유 번호 (예: `DE:AD:BE:EF:FE:ED`).
* **IP 주소 (논리적 인터넷 주소)**:
* 집 주소처럼 편지를 배달받는 번호 (예: `192.168.0.50`).
* **포트 번호 (Port)**:
* 집 안의 방문 번호! (웹 서비스: `80번`, 안전 웹: `443번`).

### 📬 전 세계 컴퓨터와 편지를 주고받는 주소 체계

> 이번 슬라이드에서는 '2. 네트워크의 기본 주민등록증: IP와 MAC 주소'에 대해 자세히 살펴보겠습니다. 화면의 다이어그램과 사진을 함께 참고해 주시기 바랍니다. 첫 번째 핵심은 MAC 주소 (물리적 주소)이며, 두 번째로는 전 세계 모든 랜카드에 유일하게 부여된 고유 번호 (예: DE:AD:BE:EF:FE:ED).입니다. 여기에 덧붙여 IP 주소 (논리적 인터넷 주소) 내용까지 함께 이해해 두시면 완벽합니다. 이 원리는 아두이노 시스템 전체를 관통하는 핵심 논리이므로 머릿속에 꼭 정리해 두시기 바랍니다.

## 3. 이더넷 라이브러리(`Ethernet.h`)의 기본 골격

![](./img/dorothy_network_bridge.jpg)

### 💻 공유기로부터 IP 주소 받아오기 (DHCP)

```cpp
#include <SPI.h>
#include <Ethernet.h>

// 고유 MAC 주소 지정
byte mac[] = { 0xDE, 0xAD, 0xBE, 0xEF, 0xFE, 0xED };

void setup() {
  Serial.begin(9600);

  // 공유기에 "IP 주소 하나만 주세요!" 요청 (DHCP)
  if (Ethernet.begin(mac) == 0) {
    Serial.println("DHCP 연결 실패!");
  } else {
    Serial.print("내 아두이노 IP 주소: ");
    Serial.println(Ethernet.localIP()); // 할당받은 IP 출력
  }
}
```

> 이번 슬라이드에서는 '3. 이더넷 라이브러리(Ethernet.h)의 기본 골격'에 대한 실제 동작 코드를 분석해 보겠습니다. 화면의 코드를 살펴보시면, 컴퓨터가 아두이노 하드웨어에 단계별로 명령을 내리는 흐름을 명확하게 확인할 수 있습니다. 각 함수의 역할과 괄호 안의 매개변수가 하드웨어 핀과 어떤 관계를 맺고 동작하는지 주의 깊게 살펴보시기 바랍니다.
