## 2. 웹서버 스케치 핵심 코드 구조

![](./img/dorothy_multi_arduino_talk.jpg)

### 💻 `EthernetServer` 클래스 활용

```cpp
#include <SPI.h>
#include <Ethernet.h>

byte mac[] = { 0xDE, 0xAD, 0xBE, 0xEF, 0xFE, 0xED };
EthernetServer server(80); // 80번 표준 웹 포트로 서버 개방

void setup() {
  Ethernet.begin(mac);
  server.begin(); // 웹서버 청취 시작!
  pinMode(8, OUTPUT);
}
```

> 이번 슬라이드에서는 '2. 웹서버 스케치 핵심 코드 구조'에 대한 실제 동작 코드를 분석해 보겠습니다. 화면의 코드를 살펴보시면, 컴퓨터가 아두이노 하드웨어에 단계별로 명령을 내리는 흐름을 명확하게 확인할 수 있습니다. 각 함수의 역할과 괄호 안의 매개변수가 하드웨어 핀과 어떤 관계를 맺고 동작하는지 주의 깊게 살펴보시기 바랍니다.

## 3. 클라이언트 요청 분석 및 HTML 응답

![](./img/dorothy_web_buttons.jpg)

### 📄 웹 브라우저로 HTML 홈페이지 전송

```cpp
void loop() {
  EthernetClient client = server.available(); // 접속한 손님 확인
  if (client) {
    // HTTP 헤더 및 HTML 본문 응답 전송
    client.println("HTTP/1.1 200 OK");
    client.println("Content-Type: text/html");
    client.println();
    client.println("<h1>Dorothy Smart Home</h1>");
    client.println("<p><a href=\"/?on\"><button>LED ON</button></a></p>");
    client.println("<p><a href=\"/?off\"><button>LED OFF</button></a></p>");
    client.stop(); // 클라이언트 접속 종료
  }
}
```

> 이번 슬라이드에서는 '3. 클라이언트 요청 분석 및 HTML 응답'에 대한 실제 동작 코드를 분석해 보겠습니다. 화면의 코드를 살펴보시면, 컴퓨터가 아두이노 하드웨어에 단계별로 명령을 내리는 흐름을 명확하게 확인할 수 있습니다. 각 함수의 역할과 괄호 안의 매개변수가 하드웨어 핀과 어떤 관계를 맺고 동작하는지 주의 깊게 살펴보시기 바랍니다.
