## 1. 수동 부저(Passive Buzzer)란? 🎼

![아두이노 로고](../../img/arduino_logo.png)

- 내부에 발진 회로가 없어 5V 직류 전원만 꽂으면 아무런 소리도 나지 않습니다.
- 대신 아두이노가 원하는 주파수의 사각파(Square Wave) 펄스를 보내주면, 진동판이 그 박자에 맞춰 정확하게 떨리며 다양한 음높이(피치)를 연주합니다.
- 능동 부저보다 응용 범위가 훨씬 넓어 멜로디 연주, 효과음, 게임 오디오 등에 두루 쓰입니다.

> 자, 이번 슬라이드의 질문을 함께 보시겠습니다. 바로 '1. 수동 부저(Passive Buzzer)란? 🎼'라는 아주 흥미로운 질문입니다. 우리가 일상에서 흔히 접하는 내부에 발진 회로가 없어 5V 직류 전원만 꽂으면 아무런 소리도 나지 않습니다. 현상을 떠올려보면 왜 이런 의문이 생기는지 쉽게 공감할 수 있습니다. 이 질문 속에 숨겨진 전자 회로와 컴퓨팅의 핵심 원리를 지금부터 차근차근 하나씩 파헤쳐 보겠습니다.

## 2. 소리의 과학: 주파수(Hz)와 음계의 비밀 🔬

![](./img/image_2_2.jpg)

- **소리의 3요소**: 세기(진폭), 높낮이(주파수), 맵시(파형).
- **주파수(Frequency, Hz)**: 1초 동안 진동판이 왕복 운동하는 횟수입니다.
- 진동이 느릴수록(낮은 Hz) $\rightarrow$ **묵직하고 웅장한 저음**
- 진동이 빠를수록(높은 Hz) $\rightarrow$ **맑고 날카로운 고음**
- 인간의 가청 주파수 영역은 약 **20 Hz ~ 20,000 Hz (20 kHz)**입니다.

> 이번 슬라이드에서는 '2. 소리의 과학: 주파수(Hz)와 음계의 비밀 🔬'에 대해 자세히 살펴보겠습니다. 화면의 다이어그램과 사진을 함께 참고해 주시기 바랍니다. 첫 번째 핵심은 소리의 3요소: 세기(진폭), 높낮이(주파수), 맵시(파형).이며, 두 번째로는 주파수(Frequency, Hz): 1초 동안 진동판이 왕복 운동하는 횟수입니다.입니다. 여기에 덧붙여 진동이 느릴수록(낮은 Hz) $\rightarrow$ 묵직하고 웅장한 저음 내용까지 함께 이해해 두시면 완벽합니다. 이 원리는 아두이노 시스템 전체를 관통하는 핵심 논리이므로 머릿속에 꼭 정리해 두시기 바랍니다.

## 3. 수동 부저 회로 결선 및 핀맵 🔌

![](./img/image_3_3.png)

* **💡 참고**: 전류를 보호하고 부드러운 음색을 내기 위해 100Ω~220Ω 저항을 직렬로 연결해 주어도 좋습니다.

- **부저 (+) 다리**: 아두이노 **디지털 5번 핀** 연결
- **부저 (-) 다리**: 아두이노 **GND** 연결

수동 부저는 극성이 없거나 양극(+) 표시가 있는 핀을 아두이노 디지털 핀에 연결합니다.

```
[아두이노 D5 핀] ---> [수동 부저 (+)] ---> [수동 부저 (-)] ---> [GND]
```

> 이번 슬라이드에서는 '3. 수동 부저 회로 결선 및 핀맵 🔌'에 대한 실제 동작 코드를 분석해 보겠습니다. 화면의 코드를 살펴보시면, 컴퓨터가 아두이노 하드웨어에 단계별로 명령을 내리는 흐름을 명확하게 확인할 수 있습니다. 여기서 핵심은 부저 (+) 다리: 아두이노 디지털 5번 핀 연결입니다. 각 함수의 역할과 괄호 안의 매개변수가 하드웨어 핀과 어떤 관계를 맺고 동작하는지 주의 깊게 살펴보시기 바랍니다.

## 5. 아두이노 음향 제어 함수: `tone()` & `noTone()` 🪄

![](./img/image_5_6.png)

- **`tone(pin, frequency)`**: 지정한 핀으로 해당 주파수의 소리를 계속 출력합니다.
- **`tone(pin, frequency, duration)`**: 지정한 밀리초(`duration`) 동안 소리를 내고 자동 정지합니다.
- **`noTone(pin)`**: 현재 출력 중인 소리를 즉시 끕니다 (쉼표 역할).

아두이노 내장 타이머를 이용해 디지털 핀에 지정한 주파수의 50% 듀티비 사각파를 출력합니다.

```cpp
tone(5, 262); // 5번 핀에서 262Hz('도') 소리 시작
delay(500);   // 0.5초 동안 유지
noTone(5);    // 소리 끄기 (쉼표)
```

> 이번 슬라이드에서는 '5. 아두이노 음향 제어 함수: tone() & noTone() 🪄'에 대한 실제 동작 코드를 분석해 보겠습니다. 화면의 코드를 살펴보시면, 컴퓨터가 아두이노 하드웨어에 단계별로 명령을 내리는 흐름을 명확하게 확인할 수 있습니다. 여기서 핵심은 tone(pin, frequency): 지정한 핀으로 해당 주파수의 소리를 계속 출력합니다.입니다. 각 함수의 역할과 괄호 안의 매개변수가 하드웨어 핀과 어떤 관계를 맺고 동작하는지 주의 깊게 살펴보시기 바랍니다.

## 6. 실습 ①: 8음계 도레미파솔라시도 계단 오르기 🪜

![](./img/image_6_7.png)

배열(`array`)과 `for` 반복문을 활용하여 8개의 음계를 차례대로 연주합니다.

```cpp
/*
 * 수동 부저를 이용한 8음계 순차 연주
 */
const int BUZZER_PIN = 5;

// 도, 레, 미, 파, 솔, 라, 시, 도 주파수 배열
int scale[] = {262, 294, 330, 349, 392, 440, 494, 523};

void setup() {
  pinMode(BUZZER_PIN, OUTPUT);
}

void loop() {
  for (int i = 0; i < 8; i++) {
    tone(BUZZER_PIN, scale[i]); // 해당 주파수 소리 재생
    delay(400);                 // 음표 지속 시간 (400ms)
  }
  
  noTone(BUZZER_PIN); // 한 옥타브 완료 후 정지
  delay(1000);        // 1초 쉬고 다시 시작
}
```

> 이번 슬라이드에서는 '6. 실습 ①: 8음계 도레미파솔라시도 계단 오르기 🪜'에 대한 실제 동작 코드를 분석해 보겠습니다. 화면의 코드를 살펴보시면, 컴퓨터가 아두이노 하드웨어에 단계별로 명령을 내리는 흐름을 명확하게 확인할 수 있습니다. 각 함수의 역할과 괄호 안의 매개변수가 하드웨어 핀과 어떤 관계를 맺고 동작하는지 주의 깊게 살펴보시기 바랍니다.

## 7. 실습 ②: 동요 "나비야 나비야" 멜로디 오르골 🦋

![](./img/image_8_8.png)

음표 주파수 배열(`melody[]`)과 음표의 박자 길이 배열(`beat[]`)을 조합하여 리듬감 있는 동요를 연주합니다.

```cpp
/*
 * 동요 "나비야" 연주 스케치
 */
const int BUZZER = 5;

// 솔 미 미, 파 레 레, 도 레 미 파 솔 솔 솔
int melody[] = {
  392, 330, 330, 
  349, 294, 294, 
  262, 294, 330, 349, 392, 392, 392
};

// 음표별 박자 배수 (1박자, 2박자)
int beat[] = {
  1, 1, 2, 
  1, 1, 2, 
  1, 1, 1, 1, 1, 1, 2
};

void setup() {
  pinMode(BUZZER, OUTPUT);
}

void loop() {
  for (int i = 0; i < 13; i++) {
    tone(BUZZER, melody[i]);
    delay(300 * beat[i]); // 박자 길이에 맞게 연주
    
    noTone(BUZZER);
    delay(50); // 음과 음 사이의 짧은 스타카토 휴식
  }
  
  delay(2000); // 1곡 완료 후 2초 대기
}
```

> 이번 슬라이드에서는 '7. 실습 ②: 동요 "나비야 나비야" 멜로디 오르골 🦋'에 대한 실제 동작 코드를 분석해 보겠습니다. 화면의 코드를 살펴보시면, 컴퓨터가 아두이노 하드웨어에 단계별로 명령을 내리는 흐름을 명확하게 확인할 수 있습니다. 각 함수의 역할과 괄호 안의 매개변수가 하드웨어 핀과 어떤 관계를 맺고 동작하는지 주의 깊게 살펴보시기 바랍니다.

## 8. 실습 ③: `#define` 매크로로 만드는 "학교종이 땡땡땡" 콘서트 🔔🎒

![](./img/image_8_9.png)

헤더 파일이나 상단 선언부에 `#define`으로 계이름을 지정하면 악보를 그대로 코드로 옮겨 적을 수 있습니다.

```cpp
/*
 * #define 매크로를 활용한 가독성 높은 음악 코드
 */
#define NOTE_C4 262
#define NOTE_D4 294
#define NOTE_E4 330
#define NOTE_G4 392
#define NOTE_A4 440

const int BUZZER = 5;

// "솔 솔 라 라 솔 솔 미"
int schoolSong[] = {
  NOTE_G4, NOTE_G4, NOTE_A4, NOTE_A4, NOTE_G4, NOTE_G4, NOTE_E4
};

void setup() {
  pinMode(BUZZER, OUTPUT);
}

void loop() {
  for (int i = 0; i < 7; i++) {
    tone(BUZZER, schoolSong[i]);
    delay(350);
    noTone(BUZZER);
    delay(50);
  }
  delay(3000);
}
```

> 이번 슬라이드에서는 '8. 실습 ③: #define 매크로로 만드는 "학교종이 땡땡땡" 콘서트 🔔🎒'에 대한 실제 동작 코드를 분석해 보겠습니다. 화면의 코드를 살펴보시면, 컴퓨터가 아두이노 하드웨어에 단계별로 명령을 내리는 흐름을 명확하게 확인할 수 있습니다. 각 함수의 역할과 괄호 안의 매개변수가 하드웨어 핀과 어떤 관계를 맺고 동작하는지 주의 깊게 살펴보시기 바랍니다.

## 9. 부저 실습 시 타이머 충돌(Timer Conflict) 주의점 ⚠️

![](./img/image_10_10.jpg)

- 아두이노 UNO의 `tone()` 함수는 **타이머 2(Timer 2)**를 사용합니다.
- 따라서 `tone()`을 사용하는 동안에는 타이머 2에 할당된 **3번과 11번 핀의 PWM(`analogWrite`) 기능이 비활성화**됩니다.
- 부저와 LED 밝기 조절을 함께 사용할 때는 3, 11번 핀 대신 **5, 6번(타이머 0)** 또는 **9, 10번(타이머 1)** 핀을 사용해야 합니다.

> 이번 슬라이드에서는 '9. 부저 실습 시 타이머 충돌(Timer Conflict) 주의점 ⚠️'에 대해 자세히 살펴보겠습니다. 화면의 다이어그램과 사진을 함께 참고해 주시기 바랍니다. 첫 번째 핵심은 아두이노 UNO의 tone() 함수는 타이머 2(Timer 2)를 사용합니다.이며, 두 번째로는 따라서 tone()을 사용하는 동안에는 타이머 2에 할당된 3번과 11번 핀의 PWM(analogWrite) 기능이 비활성화됩니다.입니다. 여기에 덧붙여 부저와 LED 밝기 조절을 함께 사용할 때는 3, 11번 핀 대신 5, 6번(타이머 0) 또는 9, 10번(타이머 1) 핀을 사용해야 합니다. 내용까지 함께 이해해 두시면 완벽합니다. 이 원리는 아두이노 시스템 전체를 관통하는 핵심 논리이므로 머릿속에 꼭 정리해 두시기 바랍니다.
