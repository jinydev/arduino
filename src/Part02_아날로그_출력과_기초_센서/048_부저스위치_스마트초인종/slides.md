## 🔔 입력(스위치)과 출력(부저)의 구조 분석

![입출력 구조도](./img/image_2_2.png)

| 구분 | 장치명 | 아두이노 핀 | 작동 원리 및 신호 흐름 |
| :--- | :--- | :--- | :--- |
| **입력 (Input)** | 택트 스위치 | 디지털 2번 핀 (`INPUT_PULLUP`) | 평소 `HIGH (1)`, 버튼을 누르면 접지되어 `LOW (0)` 발생 |
| **제어 (Brain)** | 아두이노 UNO | MCU (`ATmega328P`) | `if (digitalRead(2) == LOW)` 조건을 실시간 판단 |
| **출력 (Output)** | 피에조 부저 | 디지털 13번 핀 (`OUTPUT`) | 조건 만족 시 전류를 흘려(`HIGH`) 또는 주파수(`tone`)로 진동 발생 |

아두이노는 입력 신호를 받아 연산하고 출력 장치를 작동시키는 중앙 제어 센터 역할을 수행합니다.

> 이번에 살펴볼 내용은 '🔔 입력(스위치)과 출력(부저)의 구조 분석'입니다. 슬라이드에 정리된 표를 통해 각 항목의 특징과 수치, 차이점을 한눈에 비교해 보실 수 있습니다. 이 기본 개념을 확실히 잡아두셔야 실제 부품을 브레드보드에 꽂고 코딩할 때 실수 없이 완성할 수 있습니다.

## 🔌 회로 연결 가이드

![초인종 회로 배선도](./img/dorothy_doorbell_circuit.jpg)

* [!TIP]
* 능동 부저는 극성이 있습니다. 부저 윗면 스티커에 `+` 표시가 되어 있는 핀을 반드시 디지털 신호 핀에 연결해야 정상 작동합니다.

1. **택트 스위치 배선 (2가닥)**:
* 스위치 한쪽 다리 ➡️ 아두이노 **디지털 2번 핀 (D2)**
* 스위치 대각선 다리 ➡️ 아두이노 **GND 핀**
2. **능동 부저(Active Buzzer) 배선 (2가닥)**:
* 긴 다리 또는 `+` 표시 핀 ➡️ 아두이노 **디지털 13번 핀 (D13)**
* 짧은 다리 또는 `-` 표시 핀 ➡️ 아두이노 **GND 핀**

외장 저항 없이 아두이노의 내장 풀업 저항 기능(`INPUT_PULLUP`)을 활용하여 배선을 최소화합니다.
### 📌 핀 연결 상세표

> 이번에 살펴볼 내용은 '🔌 회로 연결 가이드'입니다. 화면의 회로도와 부품 사진을 보면서 각 핀과 배선이 어떻게 구성되어 있는지 눈으로 직접 따라와 주시기 바랍니다. 첫째로 택트 스위치 배선 (2가닥)에 유의해야 하며, 둘째로 스위치 한쪽 다리 ➡️ 아두이노 디지털 2번 핀 (D2)라는 점이 핵심입니다. 이 기본 개념을 확실히 잡아두셔야 실제 부품을 브레드보드에 꽂고 코딩할 때 실수 없이 완성할 수 있습니다.

## 💻 기본 실습: 누를 때만 울리는 전자 경적 (Active Buzzer)

![부저 작동 실습](./img/dorothy_buzzer_beep.jpg)

버튼을 누르고 있는 동안에만 `HIGH` 전압을 보내 삐- 소리를 내는 코드입니다.

```cpp
// 04.2-3 기본 초인종 코드
const int BUTTON_PIN = 2; // 스위치 연결 핀
const int BUZZER_PIN = 13; // 부저 연결 핀

void setup() {
  // 스위치 핀을 내부 풀업 모드로 설정
  pinMode(BUTTON_PIN, INPUT_PULLUP);
  
  // 부저 핀을 출력 모드로 설정
  pinMode(BUZZER_PIN, OUTPUT);
}

void loop() {
  // 스위치 상태 읽기 (누르면 LOW, 떼면 HIGH)
  int buttonState = digitalRead(BUTTON_PIN);
  
  if (buttonState == LOW) {
    // 버튼이 눌렸을 때: 부저 울림
    digitalWrite(BUZZER_PIN, HIGH);
  } else {
    // 버튼에서 손을 뗐을 때: 부저 끔
    digitalWrite(BUZZER_PIN, LOW);
  }
}
```

> 이번 슬라이드에서는 '💻 기본 실습: 누를 때만 울리는 전자 경적 (Active Buzzer)'에 대한 실제 동작 코드를 분석해 보겠습니다. 화면의 코드를 살펴보시면, 컴퓨터가 아두이노 하드웨어에 단계별로 명령을 내리는 흐름을 명확하게 확인할 수 있습니다. 각 함수의 역할과 괄호 안의 매개변수가 하드웨어 핀과 어떤 관계를 맺고 동작하는지 주의 깊게 살펴보시기 바랍니다.

## 🎵 심화 실습: 수동 부저로 딩동~ 멜로디 벨 연주하기

![멜로디 부저 연주](./img/dorothy_piezo_sound.jpg)

* [!NOTE]
* `tone(핀번호, 주파수, 지속시간)` 함수는 백그라운드 타이머 인터럽트로 소리를 재생하므로, 다음 음을 연주하기 전에 적절한 `delay()`를 주어야 음이 겹치지 않고 자연스럽게 들립니다.

수동 부저(Passive Buzzer)와 `tone()` 함수를 이용하면 진짜 현관문처럼 청아한 '솔-미' 딩동 소리를 만들 수 있습니다.

```cpp
// 딩동 멜로디 초인종 코드
const int BUTTON_PIN = 2;
const int BUZZER_PIN = 13;

// 음계 주파수 정의 (Hz)
const int NOTE_G5 = 784; // 높은 '솔'
const int NOTE_E5 = 659; // 높은 '미'

void setup() {
  pinMode(BUTTON_PIN, INPUT_PULLUP);
  pinMode(BUZZER_PIN, OUTPUT);
}

void loop() {
  // 스위치를 누르면 딩~동~ 멜로디 재생
  if (digitalRead(BUTTON_PIN) == LOW) {
    // '딩' 소리 (솔, 784Hz) 0.35초 연주
    tone(BUZZER_PIN, NOTE_G5, 350);
    delay(400); // 음 사이의 짧은 간격
    
    // '동' 소리 (미, 659Hz) 0.6초 연주
    tone(BUZZER_PIN, NOTE_E5, 600);
    delay(700); // 연주 완료 대기
  }
}
```

> 이번 슬라이드에서는 '🎵 심화 실습: 수동 부저로 딩동~ 멜로디 벨 연주하기'에 대한 실제 동작 코드를 분석해 보겠습니다. 화면의 코드를 살펴보시면, 컴퓨터가 아두이노 하드웨어에 단계별로 명령을 내리는 흐름을 명확하게 확인할 수 있습니다. 각 함수의 역할과 괄호 안의 매개변수가 하드웨어 핀과 어떤 관계를 맺고 동작하는지 주의 깊게 살펴보시기 바랍니다.
